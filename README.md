## Fitur
- Login admin
- Lihat, tambah, edit, dan hapus data mahasiswa
- Pencarian data mahasiswa
- Form registrasi mahasiswa dengan upload foto (belajar_form)

## Cara Menjalankan
1. Nyalakan Apache dan MySQL di XAMPP.
2. Clone repo ke folder htdocs:
   `git clone https://github.com/frishazna/project-php-modul05.git crud_php_mysql`
3. Buka `localhost/crud_php_mysql/generate.php` untuk membuat database.
4. Buka `localhost/crud_php_mysql/` lalu login.
   - Username: `admin`
   - Password: `adminmahasiswa`
